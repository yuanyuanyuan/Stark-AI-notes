## 客户端组件 vs 服务端组件

### 🎮 客户端组件 = 互动玩具
想象这些是可以**动**的乐高积木：

**特点：**
- 📱 在用户手机/电脑上运行
- 🎮 可以响应用户操作（点击、滑动、输入）
- ⚡ 立即反应，很快速
- 💾 可以记住一些临时信息

**例子：**
```
按钮组件：用户点击 → 立即变色 ✨
输入框组件：用户打字 → 立即显示文字 ✨
计数器组件：点击+1 → 数字立即增加 ✨
```

### 🏭 服务端组件 = 工厂预制品
想象这些是工厂里预先做好的积木：

**特点：**
- 🌐 在服务器上制作完成
- 📦 直接送到用户面前（已经做好了）
- 🔒 更安全（敏感信息不会泄露）
- 📊 可以直接获取数据库信息

**例子：**
```
用户资料展示：服务器查数据库 → 直接显示完整信息 📋
文章列表：服务器获取所有文章 → 直接显示列表 📑
统计图表：服务器计算数据 → 直接显示图表 📊
```

## 🎯 如何选择？

### 用互动性判断：

**需要用户互动 → 客户端组件**
- ✅ 按钮（点击要有反应）
- ✅ 表单（输入要实时验证）
- ✅ 弹窗（要能打开关闭）
- ✅ 搜索框（边输入边显示结果）

**只是展示信息 → 服务端组件**
- ✅ 文章内容（静态显示）
- ✅ 用户资料（从数据库获取）
- ✅ 统计数字（服务器计算好的）
- ✅ 导航菜单（固定不变的）

## 混合组件的解决方案

### 🎯 方案1：组件分层（推荐）
```
TaskCard (服务端组件) - 负责显示数据
├── 📝 TaskTitle (服务端) - 任务标题
├── 📅 TaskDate (服务端) - 截止日期
└── TaskActions (客户端) - 操作按钮区域
    ├── ✅ CompleteButton (客户端)
    └── 🗑️ DeleteButton (客户端)
```

**代码结构：**
```jsx
// 服务端组件 - 获取和显示数据
function TaskCard({ taskData }) {
  return (
    <div>
      <h3>{taskData.title}</h3>           {/* 服务端渲染 */}
      <p>{taskData.dueDate}</p>           {/* 服务端渲染 */}
      <TaskActions taskId={taskData.id} /> {/* 客户端组件 */}
    </div>
  );
}

// 客户端组件 - 处理用户交互
'use client';  // 标记为客户端组件
function TaskActions({ taskId }) {
  return (
    <div>
      <button onClick={() => completeTask(taskId)}>完成</button>
      <button onClick={() => deleteTask(taskId)}>删除</button>
    </div>
  );
}
```
