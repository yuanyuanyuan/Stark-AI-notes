## 🔍 错误分析

### 错误含义
"Cannot read property priority of undefined" 意思是：
- 代码试图访问某个对象的 `priority` 属性
- 但这个对象是 `undefined`（不存在）
- 就像你想从一个空盒子里拿东西一样

### 🛠️ 解决步骤

**步骤1：检查数据传递**
```jsx
// 🔍 调试代码 - 检查 task 对象是否存在
console.log('task对象:', task); // 在浏览器开发者工具中查看

// ⚠️ 安全访问 - 添加存在性检查
{task && task.priority && (
  <span>{getPriorityIcon(task.priority)}</span>
)}
```

**步骤2：添加默认值保护**
```jsx
// 😊 新手友好 - 安全的访问方式
const priority = task?.priority || '低'; // 如果没有优先级，默认为'低'
const icon = getPriorityIcon(priority);
```

**步骤3：完整的防错代码**
```jsx
const TaskCard = ({ task }) => {
  // 🚫 重要 - 数据验证，初学者可以复制使用
  if (!task) {
    return <div>任务数据加载中...</div>;
  }
  
  const priority = task.priority || '低';
  const title = task.title || '未命名任务';
  
  // 后面是正常的组件代码...
};
```

### 💡 预防措施
1. 总是检查数据是否存在再使用
2. 为可能缺失的属性提供默认值
3. 使用浏览器开发者工具查看错误详情
