## 📋 什么是组件设计规范？

简单说，这就是一套**写React代码的规则和模板**，让AI帮你写的代码更规范、更好用。

我们的规范包含：
- 📖 **简化版规范**: 快速开发的简化规则
- 🌱 **渐进式指南**: 3个阶段，从简单到复杂
- 🏭 **数据工厂**: 自动生成测试数据
- 🤖 **调试工具**: 帮你找bug和优化性能

## 💡 使用技巧

### 1. 如何让AI更好地理解规范
```
请仔细阅读这个React组件设计规范，特别是：
- 简化版组件模板
- 客户端组件设计指南
- 渐进式采用指南

然后严格按照规范的要求来生成代码，确保：
1. 组件命名符合规范
2. Props接口设计规范
3. 样式组织正确
4. 测试覆盖完整
```

### 2. 如何处理规范中的复杂部分
```
规范中有些部分我看不懂，请帮我：

1. 解释一下这个规范的核心要点
2. 告诉我哪些是必须遵守的
3. 哪些可以先简化处理
4. 给我具体的代码示例

我现在要做的是：[你的具体需求]
```

### 3. 如何检查代码是否符合规范
```
请检查我这段代码是否符合React组件设计规范：

[粘贴你的代码]

检查要点：
1. 组件结构是否规范
2. Props设计是否合理
3. TypeScript类型是否完整
4. 性能是否优化
5. 测试是否充分

如果有问题，请告诉我如何修改。
```
