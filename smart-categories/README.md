## 💡 使用建议

### 🎯 快速查找方法

#### 按开发阶段查找
1. **项目启动**：查看项目启动阶段的模板和指南
2. **需求分析**：使用需求分解和业务分析模板
3. **架构设计**：选择架构分析和设计模式模板
4. **编码开发**：根据技术栈选择对应的专业领域
5. **测试验证**：使用测试生成和代码审查模板
6. **部署上线**：配置CI/CD和监控运维模板

#### 按角色查找
- **新手开发者**：从入门级开始，学习基础概念
- **前端开发者**：重点关注前端开发和Web应用
- **后端开发者**：重点关注后端开发和API服务
- **全栈开发者**：关注Web应用和全栈开发流程
- **测试工程师**：深入测试工程和测试验证
- **架构师**：学习架构设计和高级内容

### 🔗 模板组合使用

#### 项目开发流程
1. **需求分解** → **架构设计** → **代码生成** → **测试验证**
2. **模板组合**：
   - [需求分解模板](../02-development-patterns/task-breakdown/requirement-breakdown-prompt-ai-analysis-20250829.md)
   - [架构分析模板](../03-analysis-prompts/code-architecture/general-architecture-analysis-prompt-developer-ai-20250829.md)
   - [代码生成模板](../01-core-framework/multi-agent-system/agents-code-agent-prompt-ai-development-20250829.md)
